# PM POSHAN Monthly Data Capture Format

This project is a static web application for preparing and managing the Pradhan Mantri Poshan Shakti Nirman (PM POSHAN) school monthly data capture format. It is designed to help schools record meal data, attendance details, grain consumption, financial information, and related monthly reporting fields in a structured and printable form.

## Overview

The application includes:

- School details capture
- Meal availed status by class group
- Daily meal and working-day tracking
- Grain and food item entry
- Cooking cost and payment details
- Bank and financial summary fields
- Printable school report format
- Local browser-only data handling for form entries

## Project structure

- [index.html](index.html) — main project landing page
- [uc 2.7/main_ucmdm.html](uc%202.7/main_ucmdm.html) — main PM POSHAN data capture form

## How to use

1. Open [main_ucmdm.html](main_ucmdm.html) in a browser.
2. Fill in school details and monthly data fields.
3. Use the month navigation and daily entry controls to manage records.
4. Use the print button to generate a printable version of the form.
5. Save the browser page data locally if needed, or keep the form entries in the browser session.

## Notes

- This is a front-end HTML application and does not require a backend server.
- It works best in a modern desktop or mobile browser.
- For an offline workflow, simply open the page directly from the filesystem.

## Suggested usage

This form is intended for education/administrative record-keeping related to PM POSHAN. Keep supporting records such as enrolment registers, school account books, and kitchen/cooking cost details available while filling it.
